## Tweet 3 (signal 1) [275]

**Signal 1: Domain Age (RDAP/WHOIS)**

Every Token Analysis now pulls the registration date for the project's website.

If a token claims to be an "established protocol" but its domain was registered 4 days ago — that's not coincidence. That's the entire web presence built around the launch.

## Tweet 4 (signal 2) [273]

**Signal 2: GitHub Analyzer**

If the token links a GitHub repo, we fetch contributors, recent commits, age, stars.

Shell repo red flags:
• 1 contributor, 0 stars
• Created 9 days ago
• 3 generic commits ("init", "first commit")
• Forked code with no original work
• Archived or 404'd
